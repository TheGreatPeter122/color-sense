# 色感测试 · Color Sense

直接游玩：https://thegreatpeter122.github.io/color-sense/

一个无需安装的颜色辨识游戏，全部代码和样式包含在 index.html 中。

- 题型：方块辨色、字符识色、交替混合题型。
- 模式：固定题数、连续答对、定时挑战。
- 可调方格布局、测试题数、挑战时长及难度曲线，支持难度上升、下降或恒定。
- 点击开始自动进入专注全屏，Esc 返回普通界面。
- 定时挑战最后 10 秒以放大的红色倒计时提醒。
- 测试记录保存在当前浏览器，查看后清除未读提示点。

颜色在 OKLab 空间随机取样，并按难度引入偏移；超出 sRGB 色域的颜色重新取样。本游戏仅供趣味体验。

## 本地打开

双击 index.html 即可离线游玩，无需启动服务器。

## 更新网站

将新版游戏单文件替换 index.html，提交并推送 main 分支；GitHub Pages 会自动重新部署。发布目录为 main 分支根目录。
